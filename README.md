# Belt Quality mod

This is repo for mod contaiment and updating.
## What is this?
This is Belt Quality mod for Factorio. It tweaks some ingame prototypes so quality can now affect belt's speed.
## How does it work?
Due to limitations of Factorio engine, parameters of entity cannot be modified after game initialization (so tou can't just set belt's speed to any desired value). To solve this problem mod creates dublicate prototypes for each conveyor/splitter/underground conveyor and for each level of quality. To convert original belts to modded ones mod provides two ways:
- Toggleable conversion in inventory - Mod adds toggleable shortcut to enable/disble conveyor conversion upon entering inventory. When Turned on all base game conveyors will be converted to modded alternatives on next inventory update.
- Selection tools - Mod also adds two new selection tools: **Belt conversion tool** and **Belt un-conversion tool**. According to their respective names they are converting/un-converting all suitable entities in selection.
